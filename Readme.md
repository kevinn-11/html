# Simulador de la Llei D'Hondt - Província de València

Aplicació web interactiva per calcular l'assignació de diputats segons el sistema electoral de la Llei D'Hondt, adaptada a la circumscripció de **València**.

## Característiques
- **Noms i vots editables**: Modifica directament els valors a la taula per provar diferents escenaris electorals.
- **Càlcul dinàmic**: S'actualitza automàticament a mesura que escrius.
- **Barrera electoral**: Aplica el filtre legal del **3%** dels vots vàlids necessaris per aconseguir representació.
- **Disseny responsive**: Implementat amb Bootstrap 5.

## Tecnologies
- HTML5 & JavaScript
- Bootstrap 5

## Desplegament
